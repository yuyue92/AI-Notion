# 订单模块演示（Vue 3 + Vite）

```bash
npm install
npm run dev
```
浏览器会自动打开 http://localhost:5173 。

- 数据来自 `src/mock/mockdata.json`，运行中的修改保存在 localStorage，点「重置数据」可恢复。
- 状态流转规则在 `src/store.js` 的 `TRANSITIONS`，与设计稿状态机一致。
- 下单预占库存；取消、超时关闭、退款成功会回补库存。

## 新增（第二版）
- 角色切换：买家 / 商家 / 客服。每个状态只有对应角色能操作，其他角色会看到由谁处理的提示；买家只能看到自己的订单。
- 支付倒计时：待支付订单 30 分钟内未支付会自动关闭并释放库存，可点「缩短到 10 秒」演示；示例数据里李佳的订单约 75 秒后会自动超时。
