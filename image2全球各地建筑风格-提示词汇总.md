# 九、适合所有提示词的“克制型负向描述”

```text
Avoid fantasy architecture, oversized structures, impossible geometry, excessive visual effects, neon overload, surreal lighting, exaggerated ruins, apocalyptic clichés, game concept art style, crowded composition, artificial HDR, oversaturated colors, distorted windows, duplicated buildings, floating objects, random text, logos, watermarks
```

# 十、一个实用公式：快速自己扩展

后续自己组合提示词时，可以按这个结构写：

```text
[建筑类型与地点]
+ [具体材质与结构]
+ [天气与季节]
+ [时间段与光线]
+ [生活化细节]
+ [镜头视角]
+ [整体氛围]
+ [真实感控制词]
```

例如：

```text
A traditional coastal village in southern Italy, weathered limestone houses with faded blue shutters and terracotta rooftops, narrow stone stairs descending toward the sea, late summer morning, soft sunlight reflecting from the water, laundry moving gently between balconies, a quiet café terrace in the distance, cinematic wide-angle architectural photography, photorealistic, realistic materials, natural colors, no fantasy elements
```

其中最值得优先尝试的是：**苏州园林、徽州村落、京都町屋、伊朗亚兹德、威尼斯晨雾、挪威木板教堂、桑给巴尔石头城、库斯科雨季街道、冰岛草皮屋、太平洋高脚村落**。这些场景辨识度高，而且不容易生成成千篇一律的旅游宣传照。
