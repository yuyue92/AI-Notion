AI对话笔记

 我需要你确认的问题
关键问题（影响脚本设计）：

输出格式选哪个？ old-format（简单汇总）还是 new-format（按周分tab）？还是两个都要？
输出是"一个总文件"还是"每人一个文件"？ 比如：所有人合并到一个xlsx的一个sheet，还是每位员工单独输出？
日期范围过滤？ 是全部数据都导出，还是只导某个时间段（比如某周/某月）？
source文件的命名规律是什么？ 是 source-data1.xlsx、source-data2.xlsx 这样的序号，还是按员工姓名命名（如 WilliamChan.xlsx）？这影响批量读取逻辑。
模板是否每次用干净的空白模板？还是往已有数据的模板里追加？
